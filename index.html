🍿 Mon cinéma

Colle l'URL de la page "à l'affiche" ou "horaires" de ton cinéma. Un lien direct sera affiché dans "Découvrir", avec un aperçu automatique si le site le permet.

☁️ Synchronisation GitHub

Le token n'est jamais exporté avec tes données (films/séries) : il vit uniquement dans le localStorage de ton navigateur et dans le lien / fichier de config si tu choisis de les générer.
Si activé, l'appli committe automatiquement sur GitHub ~4 secondes après ta dernière action (vu/non vu, ajout, etc.), sans que tu aies besoin de cliquer sur "Sauvegarder".

🔧 Maintenance

Recontacte TMDB pour chaque film et série déjà ajoutés, et met à jour affiche, synopsis, genres, casting, année, réalisateur/créateur et lien TMDB. Ne touche ni à ton statut vu/non vu, ni à la liste des épisodes (utilise plutôt "Vérifier toutes les séries" pour ça).

💾 Sauvegarde locale (fichier JSON)

Utile pour une sauvegarde manuelle ponctuelle, indépendante de GitHub.

🔐 Sauvegarde & partage des paramètres (clé TMDB, token GitHub...)

⚠️ Le fichier de paramètres et le lien contiennent ton token GitHub en clair. Ne les partage jamais publiquement, ne les commit pas dans un dépôt public. Utilise le lien uniquement pour toi-même (ex : le mettre en favori sur un autre appareil).
